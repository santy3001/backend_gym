# backend_gym

Backend para una aplicación de gimnasio desarrollado con Node.js y Express.

## Descripción
Este proyecto maneja autenticación, usuarios y módulos para organizar la lógica del backend.

## Tecnologías
- Node.js
- Express
- JavaScript
- JWT

## Instalación
npm install

## Ejecución
npm start

## Variables de entorno
PORT=3000
JWT_SECRET=tu_secreto
